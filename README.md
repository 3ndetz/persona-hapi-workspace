# Persona HAPI Workspace

Отдельная оболочка для **существующего HAPI**: вкладки, общий список сессий и
**1–6 горизонтальных чатов**. Без форка или пересборки HAPI, без новых агентов.

Обычный клик меняет левый чат; `+` рядом с сессией добавляет её справа.
Ширины колонок перетаскиваются и сохраняются отдельно для каждой раскладки.
Ввод, файлы, steer, разрешения и настройки остаются штатными функциями HAPI.

## Установка

Нужны **Node.js 22+** и уже работающий HAPI. npm-зависимостей нет.

```sh
git clone https://github.com/3ndetz/persona-hapi-workspace.git
cd persona-hapi-workspace
node proxy.mjs --upstream http://127.0.0.1:3006 --port 3096
```

Откройте **http://127.0.0.1:3096/workspace** и войдите штатным способом HAPI.
Поменяйте `3006` на порт своего HAPI. Обычный интерфейс доступен на `/sessions`.
Команда работает одинаково в PowerShell и Linux/macOS.

Для публичного доступа направьте **весь домен**, включая API/WebSocket/SSE, на
этот прокси. Например, Caddy на той же машине:

```caddyfile
workflow.example.com {
    reverse_proxy 127.0.0.1:3096
}
```

Публичный URL в конфигурации HAPI должен соответствовать этому домену.
Прокси по умолчанию слушает только localhost. Для контейнера используйте
`--host 0.0.0.0`, но не публикуйте незашифрованный порт напрямую в интернет.
Для автозапуска используйте свой systemd/Docker/Windows service manager:
эта команда сама по себе не устанавливает фоновую службу.

## Обновления и ограничения

- Обновление оболочки: `git pull`, затем перезапуск её процесса.
- HAPI обновляется обычным способом; его исходники здесь не меняются.
- Это **внешняя интеграция, не официальный plugin API HAPI**. Изменения маршрутов,
  разметки списка или политики iframe/CSP могут потребовать правки `workspace/embed.js`.
  Не отключайте CSP целиком. После обновления проверьте `/workspace` и `/sessions`.
- Несколько чатов рассчитаны на большой экран; на узком экране есть горизонтальная прокрутка.
  Много открытых вкладок потребляют больше памяти. Закрытие вкладки не останавливает агента.
- Состояние вкладок хранится локально в браузере. Токены в URL или файлы не копируются.

Для встраивания в свой Node-прокси импортируйте `serveWorkspace` и
`workspaceInjection` из `workspace/server.mjs`: обработайте статические маршруты
первой функцией и вставьте второе значение перед `</head>` **только в HTML** HAPI.
Сохраняйте общий origin и штатные API, авторизацию, WebSocket и SSE.

## Проверка

```sh
npm test
```

Тесты используют локальные фикстуры, не подключаются к реальным агентам.
Интерфейс проверен в исходной установке с HAPI 0.30.7: шесть реальных сессий,
добавление справа, замена слева, сохранение ширин и восстановление после перезагрузки.
VS Code-расширение в этот репозиторий пока **не входит**.
